Web Text Extractor

A web address in, the readable text out

Give it the address of an article, a documentation page or a standard, and it returns the text that matters — with the navigation, cookie banners, adverts, share bars and footers left behind. Nothing is rewritten or summarised: every line comes from the page itself. Check it, edit it, then copy it or send it to the Education library.

Public pages only. A site that asks automated tools to stay away in its robots.txt is respected, and nothing behind a sign-in can be read.

How to read it

Automatic reads the plain HTML and only reaches for a browser if the page comes back empty.
