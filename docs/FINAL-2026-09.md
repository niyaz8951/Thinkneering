## Map data — upload through the site
Knowledge → Admin → **Import CSV** tab. Preview, read the counts, Apply.
Everything arrives as draft; approve in the queue.

| Order | File | Map | Table |
|---|---|---|---|
| 1 | `data/knowledge-imports/dictionary-ncert-words.csv` | Dictionary (English) | Nodes |
| 2 | `data/knowledge-imports/hvac-gulf-nodes.csv` | HVAC knowledge base | Nodes |
| 3 | `data/knowledge-imports/hvac-gulf-edges.csv` | HVAC knowledge base | Edges |

Notes on what to check before approving are in `data/knowledge-imports/README.md`.

Imported nodes appear in the outline at once; on the Graph tab they land
in their lanes (an import made before this version stacked them at 0,0 —
press **Tidy by lane** once on that map; Tidy now saves positions).

**Start over?** `npx wrangler d1 execute thinkneering-db --remote --file=./db/reset-imported-nodes.sql`
removes everything Import CSV created (nodes with origin `import`, their
edges and index rows) and nothing else — hand-made, AI-proposed, dictionary
and seed nodes stay. Then import the three CSVs again; with this version they
land in their lanes, so no Tidy is needed.

Approving: Knowledge → Admin → Approval queue → **Select all shown** →
**Approve selected**, or **Approve everything waiting** for the whole queue.
Approval runs in chunks of 100 with a running count; the queue lists up to
1,000 nodes. (Before this fix, selecting more than ~100 nodes failed on D1's
bound-parameter limit — that was the "approve in one go" problem.)
