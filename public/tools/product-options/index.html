Edit is on. Add a special option or a note to a section or a row, and take out values or rows that are not options (airflow, pressure drop). Tick several rows to leave them out together. "Leave out row" applies to every factory of this product; everything else is for this factory only. Whether a row is an option or a duty figure is set on the Row mapping page (Kind).

Values are as printed on the datasheets run so far, for the rows the product's row mapping shows (one mapping per product, the same for every factory and every user). "Seen n times" is how often the value turned up; a datasheet run again is counted again. Duty figures (flows, pressures, sizes ...) are what was selected so far, shown from lowest to highest; they are not options and not limits. A value not listed here is not known yet, it does not mean the factory cannot offer it. Confirm special requests with the factory.
